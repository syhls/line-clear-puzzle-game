# 猫咪推行消除

纯 HTML、CSS、JavaScript 的 8×6 推行消除原型，无需安装任何依赖。

## 在线游玩

[打开游戏](https://syhls.github.io/line-clear-puzzle-game/)

## 运行

用浏览器直接打开 `index.html`，或在 IntelliJ IDEA 中打开此文件夹后运行/预览该页面。

## 操作

- 按住方块，向左或向右拖动；
- 松开后自动完成一次移动；
- 若移动后回到原位置，不计入操作数；
- `R` 可重新开始。

## 规则实现

- 棋盘为 8 列 × 6 行；开局会先清空棋盘，再让相连的两条随机行从中部一起出现、一起下落并进行消除检查；方块高为 1，宽随机为 1–4；
- 下落前会检查整个方块下方的所有格子；
- 满一行删除并加 8 分；删除后持续检查下落和新消除；
- 每次有效操作后先完成下落、消除与连锁下落；若顶部有空位，再以延迟动画使旧方块整体上移一格，并在最底行生成新方块；推入后再次从下往上检查下落与消除；
- 每条随机生成的新行固定占 4–7 格，绝不会填满整行；
- 开局会预演下落结果；任何会导致初始消除的两行布局都会重新随机生成。
- 顶行已有方块时无法继续上移，游戏结束。

## 方块皮肤

- 默认皮肤为 5 种颜色，每个新方块会随机分配其中一种；
- 如需替换图片皮肤，在 `game.js` 顶部的 `SKIN_SOURCES` 中填入对应图片的相对路径或网址；保留 `null` 则使用默认颜色。

## 调整方块出现比例

在 game.js 顶部修改 WIDTH_1_WEIGHT、WIDTH_2_WEIGHT、WIDTH_3_WEIGHT、WIDTH_4_WEIGHT 即可。它们是相对权重，数值越大出现越频繁，无须相加为 100。
